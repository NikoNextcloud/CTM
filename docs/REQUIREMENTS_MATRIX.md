# CTM 2.0 — матрица за приемане на пълната СТМ система

Нотация: IMPLEMENTED=има код; PARTIAL=частично; BLOCKED=задължителна предпоставка; NOT_STARTED=липсва реализация. Успешен build не доказва функционален паритет.

| Област | Статус v0.5 | Минимално доказателство за приемане |
|---|---|---|
| GitHub, Vercel, Supabase автоматизация | IMPLEMENTED | единичен release commit, READY, стабилен rollback |
| Потребители ръчно в Supabase | IMPLEMENTED | реален админ може да създаде/добави потребител |
| Роли и фирмено ограничаване | PARTIAL | end-to-end матрица за всички роли и две фирми |
| Фирмен регистър, детайли, обекти | IMPLEMENTED | създаване, редакция, изолация, pagination |
| Длъжности и структура на фирма | PARTIAL | активност, търсене, наследяване и отчети |
| Служебни/трудови записи | PARTIAL | без дубликати, история, верификация с източник |
| Оценка на риска | PARTIAL | методика, работни процеси, измервания, мерки, подписване |
| План за годишни СТМ дейности | NOT_STARTED | календар, договорен обхват, изпълнение |
| Медицински прегледи | BLOCKED | лекарско одобрение, GDPR, съхранение, тестове |
| Болнични листове | BLOCKED | проверени свързвания на записи и законови основания |
| Частни файлове и шаблони | BLOCKED | private bucket, access log, malware check, backups |
| Анализ на здравословно състояние | BLOCKED | агрегиране, преглед на обхват, защита на диагнози |
| Нормативни справки и документи | PARTIAL | одобрени шаблони и проверени изчисления |
| Одитен регистър | PARTIAL | защита от подправяне, събития за четене, retention |
| Импорт от EMS-STM | BLOCKED | SHA256 manifest, reconciliation, dry run, подписан приемателен протокол |
| GDPR DPA/DPIA и роли | BLOCKED | правен преглед, оценки, политики, регистър обработки |
| Многофирмено и multi-tenant изолиране | PARTIAL | cross-tenant атаки с отделни действителни тестови роли |
| Надеждност, backup/restore | BLOCKED | възстановяване от архив с проверена RPO/RTO |
| Производителност/пагинация | PARTIAL | тестове над 1000/10000 реда, индекси, export jobs |
| Продукционна експлоатация | BLOCKED | преминати всички горни условия и търговски план |

Правило: не маркирай BLOCKED като IMPLEMENTED от наличието на екран или SQL таблица.
